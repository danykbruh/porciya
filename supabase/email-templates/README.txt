Шаблоны писем Порции для Supabase → Authentication → Emails → Templates.
Для каждого шаблона: вставить тему (Subject) и весь текст файла в поле Message body (Source / HTML), затем Save.

Confirm signup   — тема: Подтвердите почту в Порции        — файл confirm-signup.html
Reset password   — тема: Сброс пароля в Порции             — файл reset-password.html
Change email     — тема: Подтвердите новую почту в Порции  — файл change-email.html
