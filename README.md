# Порция

<img src="icons/icon-192.png" width="96" alt="Иконка Порции">

Дневник питания: приёмы пищи, калории и БЖУ, журнал веса, недельные итоги и программа питания.

## Структура проекта

```
index.html            разметка страницы
css/styles.css        стили (светлая и тёмная тема)
js/app.js             логика приложения
js/config.js          публичные настройки Supabase (без секретов)
icons/                иконка приложения
supabase/01_schema.sql  схема базы данных и правила доступа (RLS)
```

## Запуск на компьютере

Открыть `index.html` двойным щелчком — или запустить локальный сервер:

```
npx serve .
```

и открыть http://localhost:3000

## Возможности

- **Дневник.** Приёмы пищи по дням: время, тип (завтрак / обед / ужин / перекус), вес порции, калории, БЖУ.
- **Расчёт через ИИ.** По названию блюда и весу оценивает калории, белки, жиры, углеводы и наличие овощей или фруктов.
- **Распознавание по фото.** По снимку тарелки определяет блюда, их вес, калории и БЖУ. Фото никуда не сохраняется.
- **Честный диапазон.** ИИ-оценки показываются с диапазоном и уверенностью (например, «≈ 650 ккал, 490–845, уверенность низкая»), а в итоге дня — общий диапазон.
- **Что приготовить.** Перечисляете продукты дома — ИИ предлагает блюда под оставшуюся на сегодня норму калорий и белка, с рецептом и записью в дневник в один клик.
- **Напоминания.** Если к заданному времени завтрак, обед или ужин не записан — вверху появляется напоминание; оно исчезает после записи, отметки «сегодня без…» или откладывается на 30 минут. Работает, пока приложение открыто.
- **Редактирование.** Любую запись можно исправить; при смене веса калории и БЖУ пересчитываются сами.
- **Мои данные.** Экспорт дневника и веса в CSV, удаление всех данных навсегда.
- **Приветствие.** Два коротких экрана для нового пользователя: что умеет приложение и выбор цели.
- **Конфиденциальность.** Понятная политика прямо в приложении (черновик — проверить у юриста перед запуском).
- **Избранное.** Частые блюда подставляются в форму в один клик.
- **Вес.** Журнал взвешиваний с графиком и линией цели; норма пересчитывается от последнего веса.
- **Неделя.** Калории по дням, среднее за день, средние БЖУ, регулярность питания.
- **Тема.** Системная, светлая или тёмная.
- **Порция Плюс (демо).** Экран подписки и закрытые функции; оплата не подключена, статус хранится в браузере — только для демонстрации.
- **Программа.** Цели «изменить вес», «удерживать вес», «питаться регулярно», «больше овощей и фруктов».

## Как считается программа

- Расход энергии: формула Миффлина — Сан Жеора × коэффициент активности.
- 1 кг массы ≈ 7700 ккал.
- Ограничения безопасности:
  - темп снижения не больше 1% веса в неделю (и не больше 1 кг), набора — не больше 0,5 кг;
  - норма не ниже 1200 ккал (женщины) / 1500 ккал (мужчины);
  - цель не ниже веса при ИМТ 18,5;
  - программа не строится для младше 18 лет.
- Если выбранный срок короче безопасного, план строится на пределе безопасного темпа, а дата прогноза сдвигается.
- БЖУ: белок 1,6 г/кг при изменении веса и 1,2 г/кг при удержании (от веса, не выше веса при ИМТ 25), жиры 28% калорий, углеводы — остаток.

Это ориентир, а не медицинская рекомендация.

## Где работает

Приложение сделано как артефакт Claude и использует его возможности:

| Возможность | Для чего |
|---|---|
| `db` | хранение записей в облаке, у каждого пользователя своя приватная папка `data/users/<id>/` |
| `user` | вход через аккаунт Claude |
| `sample` | расчёт калорий и БЖУ через Claude, распознавание еды по фото, подбор блюд |
| `downloads` | скачивание CSV |

Если открыть `index.html` вне Claude, приложение работает в **локальном режиме**: всё можно попробовать, но данные не сохраняются после перезагрузки, а расчёт через ИИ недоступен.

## Структура данных

```
data/users/<id>/profile            { plan: {...} }
data/users/<id>/settings           { reminders: {on, times}, skipped: {date, types} }
data/users/<id>/profile/meals/*    { date, time, type, name, grams, kcal, protein, fat, carbs, veg, ... }
data/users/<id>/profile/weights/*  { date, kg }            (id документа = дата)
data/users/<id>/profile/favorites/* { name, type, grams, kcal, kcalPer100, p100, f100, c100, veg }
```

## История версий

1. Дневник приёмов пищи.
2. Личные записи для каждого аккаунта вместо общего списка.
3. Вес порции и расчёт калорий через ИИ.
4. Программа питания с безопасными ограничениями.
5. Журнал веса, БЖУ, цели без похудения, недельные итоги, избранное.
6. Распознавание еды по фото.
7. Выбор темы: системная, светлая, тёмная.
8. Демо-подписка «Порция Плюс» (без оплаты).
9. Новое название: «Порция» (раньше «Тарелка»).
10. Честный диапазон калорий и подбор блюд из продуктов дома.
11. Напоминания о приёмах пищи.
12. Редактирование записей, экспорт CSV, удаление всех данных, приветствие, политика конфиденциальности. Вкладка «Программа» стала «Профилем».
13. Логотип и иконка: миска-мерка с едой. Файлы — в папке `icons/`.
